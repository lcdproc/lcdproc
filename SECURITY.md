# Security Policy

## Supported Versions

LCDproc is very infrequently updated (on its normal release cadence). Only the latest release is "officially" supported. If you encounter issues with an older version of LCDproc, our first recommendation will be to upgrade.

Security and vulnerability fixes usually prompt the immediate release of a new version (since that's the whole point of a security fix release).

## Reporting Vulnerabilities

Please immediately report any observed (or suspected) vulnerability as a new issue here in the "Issues" section of the project's GitHub repository. If you've written and filed a formal CVE (or are aware of one someone else has filed), please include it (by number and reference) in your issue so we can properly review it and take appropriate action. Refer to the [CVE Program](https://www.cve.org/) for details or to [report a new vulnerability to the CVE program](https://www.cve.org/ReportRequest/ReportRequestForNonCNAs).

If you prefer to report a vulnerability privately and out-of-band, you may do so by contacting the primary project manager, William Ferrell, at willfe@gmail.com. Requests for anonymity will always be respected. We're grateful for your assistance whether you're wearing a mask or not.
